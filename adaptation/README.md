# 统一适配层

`adaptation/` 是本项目唯一的源码适配入口。它把基础运行时兼容、1017 模型协议和 SM80 加速路径合并为一套最终源码树，由同一个清单和安装器完成校验与写入。

- `files/`：将写入固定 vLLM 基础镜像的最终源码文件。
- `manifest.json`：记录每个文件的基础哈希、适配后哈希和职责归类。
- `install.py`：先校验全部文件，再原子写入，避免部分安装。
- `reference/`：官方编码器、图像处理器和 tokenizer wrapper 的固定参考实现。

适配层默认关闭未经 A100 验收的实验路径；构建阶段会执行 CPU 合约检查，真实 GPU 性能和精度结果以目标机验收记录为准。
